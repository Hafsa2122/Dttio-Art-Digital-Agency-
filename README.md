# Dttio Art Digital Agency

Welcome to the frontend repository for Dttio Art Digital Agency. This project is a modern, responsive web application built with React and Vite.

## Features
- **Dynamic Layout:** Responsive masonry grids and tailored components.
- **Beautiful UI:** A visually engaging aesthetic with handwriting-style typography and consistent styling across all pages.
- **Interactive Experiences:** Seamless navigation, functional components, and animated elements.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
